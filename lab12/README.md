Сравнение Fossify Calculator 1.2.0 и исторического образца FakeBank.B.

не выполнялись. Образцы, DEX и нативные библиотеки в репозитории не размещены.

## Подтверждённые находки

У FakeBank.B есть обработчики SMS, состояния звонков и загрузки системы,
служба CoreService и компонент Device Admin с политикой force-lock.
В доступном коде найдены SmsManager.sendTextMessage, чтение телефонной книги,
передача данных контактов в HTTP-запросе, поиск пяти пакетов корейских банков,
загрузка файла .apk, вызов системного установщика и отключение собственного
компонента запуска. Это соответствует банковскому трояну со шпионскими функциями.

Из Config статически восстановлен исторический сервер `107[.]183[.]16[.]189`
с путями `/kbs.php?m=Api&a=` и `/Css/`. Адрес не проверялся на доступность.
Домен APKProtect является следом упаковщика и не включён в IOC управляющей сети.

У калькулятора нет системных разрешений SMS, контактов, камеры, микрофона,
геолокации или INTERNET. Пользовательское WRITE_GLOBAL_SETTINGS семейства Fossify
не является системным WRITE_SETTINGS. Библиотечные строки Accessibility и
телефонии сами по себе не подтверждают слежку.

работу с ярлыками, не тихую установку APK.

## Воспроизведение статического разбора

Инструмент: Python 3, Androguard 4.1.4 с декомпилятором DAD. Зависимости указаны
в requirements.txt. Скрипт принимает путь к полученному APK или URL источника,
проверяет ожидаемый SHA-256 и обрабатывает байты как ZIP/XML/DEX. Он не вызывает
код анализируемого приложения и не сохраняет удалённый APK отдельным файлом.

```sh
python analyze.py --file calculator-8-foss-release.apk --sha256 cbadb649a3622867a62cb7756968db1e67e4a9e20df20b4b2732c998549bcbb6 --out result-calculator --decompile
```

Для обфусцированного Config:

```sh
python decode_strings.py path/to/com_google_bps_bfcfc_Config.java --out decoded-config.json
```

Декодер повторяет перестановку крайних пар символов, Base64 и XOR из
Config.getSDPath. Для статического инициализатора используется контекст
`Config<clinit>`. Это преобразование строк, а не исполнение APK.

## Ограничения

APKProtect оставил шесть неразбираемых методов, включая SMSReceiver.onReceive
и CoreService.onCreate. Они перечислены в invalid-methods.txt. Анализатор
пропускает их тела только в своей модели для обработки остальных методов;
он не ремонтирует и не запускает приложение. Неполный результат DAD не является
готовым исходным проектом.

Не подтверждены фактическая выдача прав, выполнение защищённых обработчиков,
успешная эксфильтрация, платные короткие SMS-номера, блокировка звонков конкретных
банков, содержимое дополнительных файлов и текущий статус сервера. Вызов
установщика не означает тихую установку. Device Admin требует активации
пользователем. AccessibilityService в манифесте образца нет.
