# Фрагменты декомпиляции

Файлы *.java.txt содержат исходный вывод DAD из исследованных APK. Это не готовый
проект для сборки. Неразбираемые тела шести защищённых методов пропущены и отдельно
перечислены в ../invalid-methods.txt. Синтаксис DAD местами является приближённым
представлением DEX, например нулевые значения ссылок отображаются как 0.

Оригинальный образец опубликован в исследовательской коллекции ashishb/android-malware;
точный URL и SHA-256 находятся в ../../../samples.json. Файлы приведены исключительно
как доказательства статического разбора.
